Project Overview

This project demonstrates SQL analysis using Google BigQuery and public datasets. The queries were designed to answer different analytical questions using transportation and web-traffic data while applying filtering, aggregation, joins, subqueries, grouping, sorting, and calculated comparisons.

Business Questions

Which station is most frequently used by the bike with the greatest total trip duration in the Austin Bikeshare dataset?
Which Citi Bike trips differ the most from the average trip duration of their starting station?
Which Google-related Wikipedia articles receive the highest number of views by language and title?

Tools & Skills Used

SQL Google BigQuery CTEs INNER JOIN Correlated Subqueries GROUP BY Aggregation Filtering ORDER BY Aliases Calculated Fields Data Analysis

Analysis Process

  • Queried large public datasets in Google BigQuery.
  • Used aggregation functions such as SUM(), COUNT(), and AVG().
  • Grouped records to summarize activity by bike, station, language, and article title.
  • Used a Common Table Expression (CTE) to identify the bike with the greatest total trip duration.
  • Joined the CTE back to the Austin Bikeshare dataset using bike_id.
  • Used correlated subqueries to compare individual Citi Bike trips with the average duration for the same starting station.
  • Created calculated differences to identify trips that were farthest above station averages.
  • Used LIKE filtering to isolate Google-related Wikipedia article titles.
  • Sorted results to surface the most relevant observations.

Example SQL Code

WITH longest_used_bike AS ( SELECT bike_id, SUM(duration_minutes) AS total_trip_duration FROM `bigquery-public-data.austin_bikeshare.bikeshare_trips` GROUP BY bike_id ORDER BY total_trip_duration DESC LIMIT 1 ) SELECT trips.start_station_id, COUNT(*) AS trip_count FROM longest_used_bike AS longest INNER JOIN `bigquery-public-data.austin_bikeshare.bikeshare_trips` AS trips ON longest.bike_id = trips.bike_id GROUP BY trips.start_station_id ORDER BY trip_count DESC LIMIT 1;

Query Highlights

Austin Bikeshare

A Common Table Expression identifies the bike with the highest total recorded trip duration. That result is then joined back to the trip dataset to determine the starting station used most often by that bike.

New York Citi Bike

Correlated subqueries calculate the average trip duration for each starting station and compare individual trips against that benchmark. The results are ranked to identify the trips with the largest difference from their station average.

Wikipedia Page Views

The analysis filters article titles containing the word Google, aggregates views by language and title, and sorts the results from highest to lowest total views.

Key Takeaways

CTEs can break multi-step analytical questions into smaller, easier-to-understand query components.
Joins make it possible to connect an intermediate analytical result back to detailed transactional data.
Correlated subqueries allow each record to be compared against a benchmark calculated from related records.
Aggregation, filtering, grouping, and sorting can transform large datasets into focused results that answer specific analytical questions.
